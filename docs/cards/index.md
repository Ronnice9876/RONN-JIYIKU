# 🃏 卡片盒 (Zettelkasten)

> "不是记住一切，而是让知识自己长出来。"
> — 尼克拉斯·卢曼（Niklas Luhmann），德国社会学家

## 📌 什么是 Zettelkasten？

卡片盒笔记法是德国社会学家尼克拉斯·卢曼发明的**知识增殖系统**。他用这套方法在 40 年内写了 70 本书、400 篇论文——靠的不是超凡记忆力，而是一套让思想自我链接的外脑。

核心思想：**让笔记可组合**。

## 🗂️ 三类笔记

### 1. 闪念笔记 (Fleeting Note)

```text
触发：任何时刻的灵感碎片
格式：一句话，不要求完整
命运：24 小时内处理或丢弃
场景：读书划线、听播客中闪现的想法
```

### 2. 文献笔记 (Literature Note)

```text
触发：读完一本书 / 文章 / 教程
格式：用自己的话，引用原文
命运：存到原子卡片区
场景：《思考，快与慢》读完 → 系统 1 / 系统 2 的边界在哪？
```

### 3. 永久笔记 (Permanent Note) ⭐

```text
触发：把文献笔记内化时的顿悟时刻
格式：一张卡片只讲一件事，带出站链接和入站标签
命运：永久保留，持续修改
场景：「确认偏误」永久笔记 ← 链接到「锚定效应」「达克效应」
```

## 🔍 三大原则

1. **原子性**：一张卡片 = 一个想法。长文拆卡 = 永久价值翻倍
2. **自主性**：卡片不归属于某个项目，随时可重组
3. **链接性**：Wikipedia 式双向链接，让隐式关系显式化

## 🧬 知识增殖循环

```
闪念 → 文献 → 永久笔记 → 发现新关系 → 结构笔记/专题入口 → 产出/Publish
  ↑__________________________________________________________|
```
