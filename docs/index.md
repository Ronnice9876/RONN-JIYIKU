### 🃏 按方法使用

=== "☀️ PARA 分类法"

    - **Projects** — 有明确交付物的短期工作（如「出《听雪》样片」）
    - **Areas** — 长期维护的责任领域（如「知识库建设」）
    - **Resources** — 未来可能用到的参考资料（如「MkDocs 配置速查」）
    - **Archives** — 已完成/不再活跃的内容归档

=== "🌙 Zettelkasten 卡片盒"

    1. **闪念笔记** (Fleeting) — 灵感碎片，24 小时内处理或丢弃
    2. **文献笔记** (Literature) — 读完书/文章的要点记录
    3. **永久笔记** (Permanent) — 内化后的原子知识点，带双向链接
    4. **结构笔记** (Structure/Hub) — 某主题下的入口目录

## 💡 使用约定

1. **每张卡片只讲一件事** — 原子化是卡片盒的命脉
2. **链接优先于层级** — 用 `[[卡片名]]` 串联而非靠目录分类
3. **写前问自己** — 「这个知识会在什么场景被用到？」
4. **定期回顾** — 每周整理，让知识「活」起来
5. **渐进式披露** — 先写骨架，再填充细节（Seed → Sprout → Evergreen）
