# 📓 日志总览

> 日志是知识的「消化酶」——把经历转化为洞察的地方。

## 📅 日志类型

| 类型 | 频率 | 位置 | 内容 |
|------|------|------|------|
| 每日日志 | 每天 | `daily/` | 当日事件、决策、灵感 |
| 周记 | 每周日 | `weekly/` | 回顾 + 下周计划 |
| 读书笔记 | 读完书 | `reading/` | 书籍精要 + 个人评价 |
| 会议纪要 | 按需 | — | 结构化笔记（用模板） |
