# 🌱 个人成长

> 所有投资中，投资自己的回报率最高。

## 📌 子域

- **学习方法论** — 刻意练习、间隔重复、费曼技巧、建构主义
- **认知科学** — 注意力、记忆模型、决策偏差、心流
- **自我管理** — 目标系统（OKR）、精力管理、习惯回路
- **元认知** — 对自己思考过程的思考

## 🔗 与知识库的关系

个人成长是「关于知识的知识」。这个知识库本身就是个人成长的产出物。
