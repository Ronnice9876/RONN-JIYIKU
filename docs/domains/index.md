# 🧠 知识领域总览

本知识库按 **一级领域** 组织，每个领域下又可细分为子域（Sub-domain）和专题（Topic）。

## 🗺️ 领域地图

| 领域 | 核心问题 | 当前状态 | 优先级 |
|------|---------|---------|--------|
| [计算机科学](cs/index.md) | 什么是可计算的、如何高效地做计算 | 🌱 播种 | 🔥 高 |
| [工程/技术栈](engineering/index.md) | 如何把理论落地为可靠的系统 | 🌿 萌芽 | 🔥 高 |
| [数学/统计](math/index.md) | 从数据中抽象出什么规律 | 🌱 播种 | ⚡ 中 |
| [设计/美学](design/index.md) | 什么是美的、如何创造美 | 🌱 播种 | ⚡ 中 |
| [商业/经济](business/index.md) | 价值如何创造、交换、分配 | 🌱 播种 | ⚡ 中 |
| [个人成长](growth/index.md) | 人如何学习、改变、进化 | 🌱 播种 | 🔥 高 |

## 🔗 交叉关联

> 知识的威力在于交叉。鼓励你跨领域建立连接：

```
计算机科学  ←→  数学/统计    （算法理论）
工程/技术栈  ←→  设计/美学    （交互、体验）
商业/经济    ←→  个人成长    （生涯设计）
设计/美学    ←→  计算机科学  （生成艺术、creative coding）
```

## 🌳 领域成长阶段

1. **🌱 Seeding（播种）** — 框架搭好，填充 5-10 张核心卡片
2. **🌿 Sprouting（萌芽）** — 形成子域，链接开始密集化
3. **🌳 Evergreen（常青）** — 持续维护，定期进行知识审计
