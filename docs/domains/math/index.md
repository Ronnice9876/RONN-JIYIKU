# 📐 数学/统计

> 一切高级思维的语言。

## 📌 核心分支

- **概率论与统计** — 不确定性的量化（贝叶斯、蒙特卡洛、假设检验）
- **线性代数** — 高维空间的算术语义（矩阵分解、特征向量、SVD）
- **优化理论** — 怎么找到最好的解（凸优化、梯度下降、拉格朗日乘子）
- **图论** — 关系建模（网络流、最短路径、PageRank）
- **信息与计算理论** — 什么是可计算的、计算成本是什么（复杂度、熵、信道容量）

## 🔗 跨领域链接

- 概率论 → 机器学习（[AI/ML](../cs/)）
- 线性代数 → 生成艺术、3D 图形学
- 优化 → 工程调参、资源分配
- 图论 → 社会网络、知识图谱
